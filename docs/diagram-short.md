# 図解ショートの追加手順

教材の Server Component で場面データとコードを用意します。共通の `ShortPlayer` に `label`、`scenes`、`code` を渡し、教材ページではその Server Component を `LessonPage` の `short` に渡します。コードは `highlightSourceCode` と `CodeBlock` でサーバー側で生成し、`highlightedLines` に表示行番号（`firstLine` を含む）を指定します。

場面には一意の `id`、正の表示時間（ミリ秒）、タイトル、字幕、色の役割、`nodes`、`metrics`、`codeKey` を指定します。表示するコード要素を `code` の対応するキーに登録してください。場面をまたいで同じノードや指標を使う場合は、同じ ID と並び順を保ちます。ノードの `runtime` を変更すると Server／Client 間を移動します。数値の単位と例の範囲を明記します。場面が空なら枠は表示されず、無効な場面では字幕を表示して再生を停止します。

再生、一時停止、前後、もう一度、ループ、動きを減らす設定の変更を確認します。自動送りの字幕は読み上げを繰り返さず、手動操作のみ通知します。狭い画面や拡大表示でも内容と操作が隠れないことを確認します。
